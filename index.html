Privacy

No account. No tracking. No server.

The developer never receives your data, because there is no backend to receive it.

  • API keys are stored locally in your browser profile.
  • Page text goes only to the provider you selected, only when you press Summarize.
  • No analytics, no ads, no telemetry, no selling.
  • Delete everything with one button, or by uninstalling.

Read the full privacy policy →

How the request works: when you click Summarize, the extension extracts the readable text from the current tab and sends it, with your API key, straight to the AI provider you chose. Nothing passes through any other server.

FAQ

Questions

Is it free?

Yes. The extension itself is free and open source. You pay your AI provider directly for what you use — usually a fraction of a cent per summary.

Do I need an API key?

Yes, for any cloud provider. You bring your own key, which keeps you in control of cost and quality. If you'd rather run everything locally, use Ollama — no key required.

Which provider should I use?

Any you already pay for. Cheap fast models (like a small Haiku- or Flash-class model) are more than enough for summarization. The Test button tells you immediately if a key and model work.

Where are my keys stored?

Locally, in your browser profile via chrome.storage.local. They are never sent to the developer and never synced. They are transmitted only to the provider you selected.

Does it work on every page?

Any normal web page, including app-style sites and threads that use shadow DOM. It can't read browser or extension pages, and pages with no readable text (some PDFs, videos, web apps) will report that there's nothing to summarize.
